# e2j

## 概要

**e2j** は、ゲーム内ログ（英語）を日本語に変換する
**リアルタイム翻訳アドオン（Catseye Ashita用）** です。

辞書ベースの高速置換により、
チャットログ・システムメッセージなどを即座に日本語化します。

---

## 主な機能

* 英語ログ → 日本語へリアルタイム翻訳
* 完全一致 + 部分一致のハイブリッド翻訳
* 複数単語フレーズ対応（長文優先）
* `{}` タグ保護（ログ構造を壊さない）
* 不正文字・制御コード除去
* Shift-JIS変換対応（FF11環境向け）
* 未翻訳ログの収集（任意）

---

## 動作イメージ

```text
[Before]
You gain the effect of Attack Boost.

[After]
攻撃力アップの効果を得た。
```

---

## ファイル構成

```text
e2j/
├─ e2j.lua        ← メインアドオン
├─ dict.lua       ← 翻訳辞書
├─ fetch.py       ← 辞書生成用（任意）
└─ unknown.txt    ← 未翻訳ログ
```

---

## 導入方法

1. フォルダを Ashita の `addons` に配置
2. ゲーム内で読み込み

```text
/load e2j
```

---

## 辞書について

`dict.lua` は Lua テーブル形式：

```lua
return {
    ["Attack Boost"] = "攻撃力アップ",
    ["You gain"] = "あなたは得た",
}
```

---

## 翻訳ロジック

### ① 前処理

* 制御文字除去
* 不正バイト削除
* 記号正規化

---

### ② タグ保護

```text
{player} → ##BR1##
```

→ 翻訳後に復元

---

### ③ 完全一致

```lua
dict[msg]
```

---

### ④ 部分一致（長い順）

* 文字列長でソート
* 長いフレーズを優先して置換

```lua
"attack speed" → OK
"attack" → 後処理
```

---

### ⑤ 復元

```text
##BR1## → {player}
```

---

## 特徴（重要）

### ✔ 長いフレーズ優先

誤翻訳を防止：

```text
attack speed → 攻撃速度
attack → 攻撃
```

---

### ✔ 安全な置換

* `{}` を壊さない
* 色コード除去済み

---

### ✔ 高速

* 辞書ルックアップのみ
* 外部API不要

---

## 未翻訳ログ収集（任意）

```lua
-- log_unknown(clean_log(msg))
```

有効化すると：

```text
unknown.txt
```

に保存される

→ 辞書強化に使える

---

## 注意事項

* 機械翻訳ではなく**辞書ベース**
* 辞書が無い文章は翻訳されない
* SJIS非対応文字は欠落する可能性あり
* 大量辞書はパフォーマンスに影響

---

## カスタマイズ

### 翻訳精度アップ
